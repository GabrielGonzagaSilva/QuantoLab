Política de privacidade

As calculadoras foram pensadas para funcionar com o mínimo de coleta de dados.

Dados das calculadoras

Na versão atual, os valores que você digita nas calculadoras são usados pelo JavaScript da própria página para fazer a conta no seu navegador. O QuantoLab não precisa de conta ou login para realizar esses cálculos.

Os campos das calculadoras não enviam seus salários, valores de projetos ou outros números pessoais para um banco de dados do QuantoLab.

Dados técnicos do acesso

Como qualquer site hospedado na internet, a infraestrutura pode processar informações técnicas necessárias para entregar a página, como endereço IP, data e hora do acesso, navegador e dados de segurança da conexão.

Publicidade e medição

Os espaços marcados como “Publicidade” são apenas áreas reservadas enquanto não houver um serviço de anúncios ativo. Caso ferramentas de análise, publicidade ou cookies sejam adicionadas, esta política deverá ser atualizada antes ou junto da ativação desses recursos.

Segurança

O site usa HTTPS e políticas de segurança no navegador para reduzir riscos como carregamento de código não autorizado, uso indevido em iframe e acesso desnecessário a recursos do dispositivo.

Alterações

Esta política pode ser atualizada quando o QuantoLab ganhar novos recursos. Mudanças relevantes devem ser refletidas nesta página.

Resumo: os números digitados nas calculadoras atuais são processados localmente no navegador e não são usados para criar um cadastro do usuário.
